# Security policy

Do not post secrets, room tokens, private user information, or working exploit details in a public issue.

If GitHub private vulnerability reporting is enabled, use that mechanism. Otherwise contact the repository maintainer privately before disclosing sensitive technical details.

Useful reports include:
- affected commit/version;
- reproduction steps;
- whether the issue crosses room/player boundaries;
- whether server authority, RNG, hidden selections, reconnect, or room isolation are affected.
