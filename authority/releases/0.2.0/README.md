# Release authority 0.2.0

rulesVersion: 0.2.0
visualVersion: 0.2.0

This authority extends the historical 0.1.0 roster to ten champions. The original six profiles, their assets, the Foundry background and all combat mechanics remain unchanged. The 13 historical documents and RULES_LOCK.json remain intact in authority/.

`champions.json` is the release snapshot of public/champions.json. The new profile rationales, screening conditions, all 55 pairings and flagged limitations are in docs/ROSTER_EXPANSION_BALANCE.md. Public ASSET_MANIFEST.json includes 60 measured frames. The historical manifest is preserved as authority/ASSET_MANIFEST_0.1.0.json.

The 0.2.0 version records roster and visual expansion. It does not rename the historical rules, overwrite their numbers, introduce a new trait, or authorize post-release features. The submission gate is recorded separately in docs/SUBMISSION_RELEASE_REVIEW.md.
